### **Описание задачи**

Создание **веб-сервиса** для получения/редактирования данных из вашей БД. Требуется разработать все методы для реализации итоговой бизнес логики вашего приложения. Для изображений `услуг` использовать `Minio`.

#### **Требования к веб-сервису**

| Требование | Описание |
| :--- | :--- |
| **Архитектура** | Методы и `url` в `API` должны соответствовать `REST`. В начале адреса каждого метода добавьте `/api` |
| **Фильтрация** | Для списка `услуг` и `заявок` (по статусу и диапазону даты формирования) нужна фильтрация на бэкенде. |
| **БД** | Взаимодействие с БД через `ORM`. Не делать `POST` `заявки` напрямую. |
| **Логика видимости** | Записи в статусе `удален` на клиент не передаются. |
| **Статусы** | `Создатель` удаляет и формирует черновик заявки; `Модератор` отклоняет и завершает сформированную заявку. |
| **Singleton** | Пользователь `создатель` зафиксирован во всех методах — укажите его константой через функцию-`singleton`. |
| **Системные поля** | `id`, `статусы`, `создатель/модератор`, `даты` — передавать с клиента для изменения запрещено. |

### **API Эндпоинты**

#### **Домен услуги**

| Метод | Описание |
| :--- | :--- |
| **GET** | Список с фильтрацией |
| **GET** | Одна запись |
| **POST** | Добавление (без изображения) |
| **PUT** | Изменение |
| **DELETE** | Удаление (включая удаление изображения из `Minio`) |
| **POST** | Добавление в заявку-черновик (создается автоматически с `создателем` и статусом) |
| **POST** | Добавление изображения по `id` услуги (замена старого в `Minio`, генерация имени на латинице) |

#### **Домен заявки**

| Метод | Описание |
| :--- | :--- |
| **GET** | Иконка корзины (возвращает `id` черновика и количество услуг) |
| **GET** | Список (фильтр по датам и статусу, без `удаленных` и `черновиков`). Поля через логины. |
| **GET** | Одна запись (поля заявки + список её услуг с картинками) |
| **PUT** | Изменение полей заявки по теме |
| **PUT** | Сформировать создателем (проверка полей, простановка даты формирования) |
| **PUT** | Завершить/отклонить модератором (расчет стоимости/доставки по формуле из лаб-2) |
| **DELETE** | Удаление (дата формирования) |

#### **Домен м-м (связи)**

| Метод | Описание |
| :--- | :--- |
| **DELETE** | Удаление из заявки (без `PK м-м`) |
| **PUT** | Изменение количества/порядка/значения в м-м (без `PK м-м`) |

#### **Домен пользователь**

| Метод | Описание |
| :--- | :--- |
| **POST** | Регистрация |
| **GET** | Поля пользователя после аутентификации (личный кабинет) |
| **PUT** | Редактирование пользователя (личный кабинет) |
| **POST** | Аутентификация |
| **POST** | Деавторизация |
