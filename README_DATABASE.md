# Система расчета массы экзопланет - Лабораторная 2

## Описание
Веб-приложение для расчета массы экзопланет с использованием астрономических инструментов. Реализована база данных PostgreSQL с ORM операциями и логическим удалением через SQL.

## Архитектура БД

### 4 основные таблицы:

1. **`users`** - пользователи системы (исследователи)
2. **`instruments`** - астрономические инструменты (услуги)
3. **`calculations`** - расчеты массы экзопланет (заявки)
4. **`calculation_instruments`** - связь расчетов с инструментами (м-м)

### Статусы заявок:
- `черновик` - текущая заявка пользователя (корзина)
- `удалён` - логически удаленная заявка
- `сформирован` - заявка сформирована пользователем
- `завершён` - заявка завершена модератором
- `отклонён` - заявка отклонена модератором

## HTTP методы (5 штук):

### GET методы (3):
1. `GET /` - список инструментов с поиском
2. `GET /instrument/{id}` - детали инструмента
3. `GET /calculation/{id}` - просмотр заявки

### POST методы (2):
4. `POST /add-to-calculation` - добавление инструмента в заявку (ORM)
5. `POST /delete-calculation/{id}` - логическое удаление заявки (SQL UPDATE)

## Запуск системы

### 1. Запуск Docker контейнеров
```bash
docker-compose up -d
```

Это запустит:
- PostgreSQL на порту 5432
- Adminer на порту 8080
- MinIO на портах 9000-9001

### 2. Установка зависимостей Go
```bash
go mod tidy
```

### 3. Запуск приложения
```bash
go run main.go
```

Приложение будет доступно на http://localhost:8081

## Функциональность

### ORM операции:
- Получение и поиск инструментов
- Добавление инструмента в заявку
- Просмотр заявки с инструментами

### SQL операции:
- Логическое удаление заявки через UPDATE

### Особенности:
- У каждого пользователя не более одной заявки в статусе "черновик"
- При отсутствии заявки она создается при добавлении первого инструмента
- Удаленные заявки не отображаются
- Карточка корзины неактивна при отсутствии текущей заявки
